## Coding conventions

- TypeScript everywhere. Avoid `any`.
- Use **Server Components** by default. Add `"use client"` only when a component needs state, effects or browser APIs.
- **Cache Components is on:** data access is dynamic by default. Cache it explicitly with `"use cache"`, and wrap dynamic or uncached parts in `<Suspense>`. Check the Next.js docs in `node_modules/next/dist/docs/` before using caching APIs.
- **React Compiler is on:** don't add `useMemo`, `useCallback` or `React.memo` by hand for performance. The compiler memoizes automatically. Write plain, idiomatic React and follow the Rules of React (pure render, no mutating props or state).
- Use the `@/` import alias instead of deep relative paths.
- Style with Tailwind utility classes. Keep global CSS minimal.
- Secrets go in `.env.local` (git-ignored). Never commit them. Add them to Vercel → Project → Settings → Environment Variables.
- Keep components small and focused. Put reusable UI in `src/components/`.

## Git workflow (strict)

1. **Never commit to `main`.** It's protected: PRs are required, and force pushes and deletion are blocked.
2. Start from the latest main: `git switch main && git pull`
3. Create a branch: `git switch -c <type>/<short-description>`
   - Types: `feature/`, `fix/`, `chore/`, `docs/`, `test/`, `refactor/`
4. Make small, focused commits using **Conventional Commits**: `feat: add contact form`, `fix: correct nav link`
5. Before pushing, run `npm run lint` and `npm run build`. Both must pass.
6. Push with `git push -u origin <branch>`, then open a PR (`gh pr create --fill`).
7. Check the **Vercel preview URL** that the bot comments on the PR, and review the diff.
8. **Squash and merge.** The branch is deleted automatically. Then locally run `git switch main && git pull && git branch -D <branch>`.
9. Vercel deploys `main` to production automatically.

## Decisions log

| Date | Decision | Why |
|---|---|---|
| 2026-11-22 | Next.js App Router + TS + Tailwind + ESLint | Course standard, production-grade defaults |
| 2026-11-22 | Squash-merge only, auto-delete branches | Linear, readable `main` history (one commit per PR) |
| 2026-11-22 | Public repo | GitHub Free only enforces branch rulesets on public repos |
| 2026-11-22 | Deploy via the Vercel GitHub App (no Vercel CLI) | Automatic preview per PR and production on merge |
| 2026-11-25 | `src/` directory | Keeps app code apart from config files at the root |
| 2026-11-25 | React Compiler enabled | Automatic memoization, so no manual `useMemo`/`useCallback`. Costs slightly slower builds (Babel) |
| 2026-11-25 | Cache Components enabled | Next.js 16's explicit caching model (`"use cache"` + Suspense) |
| 2026-11-25 | Keep `AGENTS.md`, imported from `CLAUDE.md` | Makes AI agents use the version-matched Next.js docs, not outdated training data |
| 2026-11-25 | Agent feedback (anonymized telemetry) off | Not needed; can be enabled with `experimental.agentFeedback` |
